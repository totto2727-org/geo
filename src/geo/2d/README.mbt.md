# @totto2727/geo

`@totto2727/geo` is a MoonBit port of [georust/geo](https://georust.org/) for two-dimensional planar and geographic geometry. Coordinates use `Double`; the module includes geometry types, robust predicates, spatial indexing, and algorithms for measurement, topology, transformation, simplification, and triangulation.

This document is canonical `README.mbt.md`; maintain `README.md` as the relative symlink `README.md -> README.mbt.md`.

## Usage

Construct geometry values in the `totto2727/geo/geo/2d/type` package and call algorithms from `totto2727/geo/geo/2d`:

```mbt check
///|
test "polygon area and centroid" {
  let polygon = @type.Polygon::Polygon(
    @type.LineString::from_tuples([
      (0.0, 0.0),
      (10.0, 0.0),
      (10.0, 10.0),
      (0.0, 10.0),
      (0.0, 0.0),
    ]),
    [],
  )
  @test.assert_eq(HasArea::unsigned_area(polygon), 100.0)
  @test.assert_eq(
    HasCentroid::centroid(polygon),
    Some(@type.Point::from_tuple((5.0, 5.0))),
  )
}
```

## Key features

- 2D geometry primitives: `Coord`, `Point`, `LineString`, `Polygon`, multi-geometries, `Rect`, `Triangle`, and `Geometry`.
- Planar algorithms for area, distance, topology, containment, DE-9IM relations, hulls, affine transforms, simplification, boolean operations, buffering, and repair.
- Geographic distance and area algorithms using Haversine, Vincenty, Rhumb, cross-track, densification, and Chamberlain-Duquette calculations.
- Robust predicates from `robust`, plus an R-tree spatial index for indexed queries and nearest-neighbor operations.
- Public API documentation is generated by Mooncakes and behavior examples are checked with MoonBit documentation tests.

## Setup

1. Add the published module to your MoonBit project.

```bash
moon add totto2727/geo@0.1.2
```

2. Import the package that owns the geometry or algorithm API in your `moon.pkg` file. The common packages are `totto2727/geo/geo/2d`, `totto2727/geo/geo/2d/type`, `totto2727/geo/robust`, and `totto2727/geo/rtree`.
